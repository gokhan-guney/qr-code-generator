# qr-code-generator
QR Code Generator

Metin, bağlantı ve Wi-Fi bilgilerini tarayıcıda QR koda dönüştüren ücretsiz araç. Renk, boyut, kenar boşluğu ve hata düzeltme düzeyini ayarlayın, QR kodunuzu PNG olarak kaydedin.


A free, browser-based QR code generator for text, links, and Wi-Fi credentials. Customize the colors, size, margin, and error correction level, then save your QR code as a PNG.
